01　定位

一个不上传的相册

云相册替你保管照片，代价是先把照片交出去。PhotoManagementSys 反着来：照片始终躺在你的硬盘里，识别、检索、整理全部在本机完成，断网照样能用。

它是什么

桌面端的个人照片库

面向个人照片库的 Windows 桌面应用。相册是对本地文件夹的抽象——导入已有文件夹，或新建相册再绑定目录；改名、移动、归类都不动原始文件。

它凭什么

内置离线 AI 微服务

随应用打包的 VCR 视觉识别服务，基于 ONNX Runtime 在本机完成分类、检测、人脸与 OCR 推理。模型在应用内下载，可切换档位，也可开 GPU 加速。

02　能力

它替你做哪些事

从「把照片导进来」到「三秒内找到那一张」，中间的整理、归类、找人、修图都在同一个应用里完成。

01

相册管理

创建、编辑、重命名、设封面、加标签与地点；支持直接导入本地文件夹，相册与磁盘目录一一对应。

02

智能分类

照片自动归入 9 大类，动物再细分为狗、猫、鸟；文档走 OCR，另有场景识别与夜景判定。

03

人物识别

人脸检测与特征提取，自动聚合同一个人；可改名、合并、删除误检，头像自动生成。

04

时间线 · 回忆

跨相册按时间铺开全部照片；按人物、地点与节日聚合成一段段可回看的回忆。

05

智能搜索

标题、标签、地点、内容组合搜索；EXIF 参数、影调与 AI 类别三合一过滤，层层收窄。

06

创意工坊

传统图像算子按参数面板驱动，可叠加 AI 处理与手绘蒙版；前后对比支持并排与分割线拖动。

07

批量操作

批量设置地点与标签、批量移入相册、批量导出到文件夹；分组树与手动排序随手整理。

08

多用户与安全

同机多账户，相册与搜索按登录用户隔离；密码 Argon2id 加盐，敏感字段 AES-256-GCM 落库。

09

模型管理

应用内下载模型，官方与镜像源自动择优；分类模型五档切换，GPU 加速一键开关。

以上能力均在本机执行。缩略图、人物头像与 GPS 反查省市同样离线完成，只有下载模型时需要联网。

03　界面导览 · 入口

四块入口，一眼看懂

主页不做信息堆叠，只回答一个问题：接下来要去哪儿。四个板块对应四条主线——整理、入库、修图、检索。

A相册管理　创建相册、绑定本地文件夹、设封面。相册只是索引，目录结构与文件本身保持不变。
B图片扫描　批量入库：读取 EXIF、判定影调、跑 AI 识别，按拍摄年份与地点自动整理。
C创意工坊　区域直方图均衡化、基准调色与图像处理算子，参数实时预览。
D智慧相册　时间线、智能搜索、人物总览与回忆——所有「找照片」的动作都在这里收口。

06　架构

三层进程，各管一段

桌面壳、业务后端与 AI 推理拆成独立进程，用固定契约通信。AI 换模型、改推理栈，都不牵动照片与数据库那一侧。

前端VUE 3
渲染进程 · WebView Vue 3 + TypeScript + Vite + Pinia + Vue Router，负责界面渲染、状态管理与后端命令调用。
↓　TAURI IPC（invoke 命令 / 事件）
后端RUST
Tauri 主进程 命令层 #[tauri::command] · 业务层 db / photo_scan / thumbnail / tone / content / persons / auth / geo_index · 持久层 SQLite。
↓　HTTP　REST　127.0.0.1
微服务PYTHON
VCR 视觉内容识别 FastAPI + ONNX Runtime，接口 / 服务 / 持久化 / 基础设施分层。YOLOv8 分类与检测、SCRFD 人脸、ArcFace 识别、PaddleOCR 文字。
桌面壳Tauri 2.x（Rust）　·　Windows x64
Rust 后端rusqlite（内置 SQLite）· image / jpeg-decoder · kamadak-exif · walkdir · argon2 · aes-gcm · reqwest · tokio
Python 微服务FastAPI + uvicorn · onnxruntime · Pillow · numpy · opencv-python
AI 模型YOLOv8s/n-cls（分类）· YOLOv8n-det（检测）· SCRFD（人脸框）· ArcFace（人像向量）· PaddleOCR（文字）
微服务打包为独立可执行文件，端口在冷门段动态分配并落盘，避免与其他程序抢占 8765；服务异常时主程序照常可用，只是 AI 相关功能降级。

07　工程细节

快一点，再稳一点

本地应用的体验上限，往往卡在 IO 与解码上。这些数字都来自真实相册的实测，而不是参数表上的理论值。

缩略图解码改用 jpeg-decoder 的 DCT 降采样，只解所需块：6000×4000 大图换封面 7.7s → 0.76s（约 10 倍）。
批量识别单次最多 64 张分批提交，进度事件实时回传，识别中界面照常可用。
离线地理内嵌省市边界数据做点面判断，GPS 反查在本地完成，不逐张联网反编码。
三合一扫描EXIF、影调、AI 内容在一次组合扫描中跑完，避免同一目录反复遍历。
渲染策略照片网格分页渲染、缩略图缓存落盘；封面与列表不再整页等待。

隐私不是设置项，是默认值

照片、缩略图与人物数据全部存放于本机数据目录，不上传、不回流；跨机迁移只需拷贝文件夹与 photos.db。密码用 Argon2id 加盐哈希，邮箱、手机号等敏感字段以 AES-256-GCM 加密落库，登录态支持三天免密。

所有推理在本机进行——这意味着模型、算力与数据都在你手里，也意味着第一次使用需要手动放置模型文件（见下页）。

08　开始使用

三步，把照片接进来

安装包约 108MB，内含识别微服务但不含模型（模型压缩包约 529MB）。看图、相册管理与调色不依赖模型，可以先装先用。

安装应用下载 v0.4.3 安装包：NSIS 按用户安装、无需管理员权限；或 MSI 按机器安装到 Program Files。
放置模型下载 model.zip，解压到安装根目录。已装过 v0.4.2 的用户无需重复下载；也可以在应用内直接下载并切换档位。
注册并导入注册账号 → 新建相册并选择本地图片文件夹 → 在详情页执行「组合扫描」，分类、人物与时间线随之生成。

支持 jpg / jpeg / png / webp / gif / bmp。首次扫描大相册会花一些时间，之后只做增量探测。

照片是你的，识别也该是你的。
