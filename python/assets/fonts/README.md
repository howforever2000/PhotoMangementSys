# 随包字体目录

卡片上的中文**由代码画**（不让生成模型画字，否则出乱码、且每次字都不一样），
所以这个目录里必须放一款**可再分发**的开源中文字体。

## 现在需要做什么

放一个（多个也行，按文件名排序取第一个）`.ttf` / `.otf` / `.ttc` 文件进来，例如：

- 思源黑体 / Noto Sans SC（SIL OFL 1.1）
- 霞鹜文楷 LXGW WenKai（SIL OFL 1.1）
- 更纱黑体 Sarasa Gothic（SIL OFL 1.1）

体积参考：思源黑体 Regular 全量 ≈ 10MB，子集化后 ≈ 2–5MB。
exe 体积预算 40MB，放一款即可，不要放字重全家桶。

## 没放会怎样

`python/agent/imaging/imageio.py` 的 `find_font()` 会退回系统字体
（Windows 的微软雅黑/黑体/宋体）。**开发机上看不出问题，用户机器上也不一定出问题，
但这是版权风险**：随安装包分发系统字体是不允许的。

渲染结果里的 `fontSource` 字段会如实写明来源（`bundled:xxx` / `system:xxx` / `none`），
出问题时看它就知道字是从哪来的。

## 为什么目录里要留一个 README

PyInstaller 的 `datas` 在源目录不存在时会**直接打包失败**。
留个文件保证目录始终存在，构建脚本就不用为"有没有字体"写分支。
