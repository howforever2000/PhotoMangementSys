## 二、本轮要解决的四个具体问题（都对着截图指认）

### 问题 1｜SmartAlbum 概览：23 个容器，一屏"全是板"

截图现象：11 块玻璃 widget 各带填充 + 边框 + 投影，块与块之间还有 14px 缝。
缝里露出壁纸 → 眼睛读到的是"11 块板排在墙上"，不是"一组数据"。

**提案**：保留 widget 的**信息**（一块不少），把**容器压到 1 个**
—— 整面墙只做一块通栏玻璃板（`--panel-glass-*`），
内部再用发丝线分成若干区（照片库总览 / 索引状态 / 那年今日 / 人物 / 地点…）。
这样"错落"改由**内部栅格宽窄**（7/5、5/7、12 通栏）承担，而不是靠板与板的缝。

### 问题 2｜Home：四张等宽玻璃卡 + 1000px 居中，与全站不对齐

截图现象：`max-width: 1000px` 居中，而其余页面是 `--sp-8` 全宽；
四张卡同一尺寸同一圆角同一阴影（通用卡片套件第 4 条特征）。

**提案**：
- 去掉 1000px 居中，改 `padding: 0 var(--gutter)`，与其余 8 页同一左轴
- 四张卡去掉玻璃底，改**裸文字行**（图标 + 标题 + 一句说明 + 右侧动作），
  行与行之间一根发丝线；第一张（相册管理）占整行宽，
  后三张在第二行按 4/4/4 排列 —— 错落来自"第一张宽"这一处
- 用户区（头像/主题/设置）从胶囊改成一行文字按钮，贴在标题右侧

### 问题 3｜AlbumList 数据带：5 列里 4 条金色进度线，强调色用光

截图现象：`已入库` 一格金色、`占用` 一格金色、`待入库` 一格金色 ——
`tokens.css §2.7` 自己写着"强调色只允许出现在当前项 / 变化值 / 图表高亮三处"。

**提案**：金色只留**一处**（`已入库` 的占比线，因为它回答"库建好了吗"这个核心问题）；
`占用` / `相册` / `待入库` 三列改成弱色占比线或不画。

### 问题 4｜文字色档数与对齐细节

- AlbumList 实测 **7 档文字色**（目标 ≤4）：来源是 `--c-fg-2` / `--color-text-2` / `--fg-2` / `opacity:.7` 混用
- 页面左右留白：Home 用 `24px`、AlbumDetail 用 `max-width:1200 + 24px`、
  其余 7 页用 `--sp-8`(52px) —— **三套留白**
- 标题层级：AlbumList/Timeline/SmartSearch/AlbumDetail 四处都有页内大标题，
  而顶栏已经有同名标题（同一信息说两遍）
