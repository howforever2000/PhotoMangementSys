# 界面质感第三轮 · 效果落地（FEAT-116）

> 分支 `dev` · 2026-10-26
> 用户诉求（原话）：**简约但有质感 / 有必要的统计信息 / 文字嵌入背景 / 卡片里文字也嵌入 /
> 卡片错落但整体整齐 / 整体风格统一 / 浅色预设几组差不多，要有不同侧重 /
> 优化液态玻璃材质**。附带约束：**首页保持原样**。

---

## 零、这一轮改的是"声部"，不是"颜色"

对着改前的截图（`.visual/out/` 里保留的对照可复现）数了一下：

| 现象 | 数量 |
|---|---|
| 概览页玻璃板 | 11 块，全部同尺寸权重（span 4/8 混排，但材质完全一样） |
| 同一读数出现的次数 | GPS 覆盖率 3 次、人物数 4 次、相册数 3 次 |
| 金色出现处 | 4 条进度线 + 1 个环 + 1 组排名条 ≈ 6 处（预算写着"只许 3 处"） |
| 浅色预设 | 6 套里 3 套是"暖白"的细微变体（顶段色相 30°±5、明度差 <0.03） |
| 浅色玻璃板 | 叠了 30% 暗罩 → 一屏十一块灰塑料 |

结论：问题不在配色，而在**所有块都是同一种材质、同一种排版**。

## 一、仪表墙：拆成两个声部

- **bare（无板）**：照片库总览 / 今年月度 —— 纯读数直接印在页面背景上。
- **panel（玻璃板）**：相册 / 人物 / 地点 / 最近导入 / 那年今日 —— 有内容才配板。

板从 11 → 5。`UiWidget` 新增 `variant="bare"`，以及两种媒体排布：
`bleed`（照片铺到板的三条边）与 `cover`（整块板就是一张照片，标题浮在上面）。
后两者解决的是"一块板里同时有板边和照片边"的双层边界。

**错落**由 7/5 → 4/4/4 → 8/4 的列宽节奏承担，**整齐**由三条共享基线承担：
标题行固定 18px、各行末元素贴底（`margin-top:auto`）、数字一律 `tabular-nums`。
行高 86 → 116，让三行填满 900px 视口。

## 二、统计：一条信息只出现一次

| 被删的块 | 信息去哪了 |
|---|---|
| 语义索引（独立块） | 照片库总览的右栏（发丝竖线分隔） |
| 内容分类（独立块） | 照片库右栏的一行 + 相册块脚注 |
| 人物照片覆盖（环） | 人物块脚注 |
| 地点定位覆盖（环）+ 排名条 | 地点块脚注（含 Top 城市） |
| 那年今日速览（小卡） | 只保留满幅大卡 |

金色收敛到 **2 处**：已入库占比线、今年当月的柱。

## 三、液态玻璃

- **浅色**：删掉 30% 暗罩，改白霜（58~64% 白 + blur 30 + saturate 1.45）+ 贴边实影。
  面板比页面底更亮 —— 浮起感来自明度差与影，不来自描边。
- **深色**：删掉 `0 0 0 1px` 四边暗环（FEAT-113 只删了亮环，暗环还在），
  边界全部由「上缘 1px 受光 + 下缘 1px 背光 + 贴边实影 + 环境柔光」承担。
- `.panel-glass`（扫描页/大面板）与 `.ui-widget--glass` 统一到同一套壁厚语言，
  同样去掉 `border: 1px solid`。
- 悬停不再改描边（没有描边了），改为"板面提亮 8%"。

## 四、预设：一轴一套

浅色六套按**色相 × 彩度**分工，并整体压深一档（顶段 L 0.95~0.97 → 0.90~0.95）——
上一版顶段几乎是纯白，白玻璃板叠在白底上只能靠描边存在。

| 预设 | 色相 | 彩度 | 侧重 |
|---|---|---|---|
| 亚麻暖灰 | 36° | 0.37 | 暖中性 · 日间浏览 |
| 纸白中性 | — | ≈0 | 纯中性 · 打印前校对 |
| 雾光冷灰 | 214° | 0.37 | 冷中性 · 长时阅读 |
| 青瓷浅绿 | 150° | 0.23 | 绿调 · 自然植物 |
| 陶土暖砂 | 27° | 0.61 | 暖彩 · 食物室内 |
| 菊芋淡紫 | 283° | 0.42 | 紫调 · 人像创作 |

每套新增 `role`（弹窗里显示"这套适合什么"，替代原来的"浅色 · 72%"）
与 `accent/accent2`（只作用于仪表墙强调色，不动全站落日金）。

## 五、顺带修掉的两个真 bug

1. **冷启动后浅色预设必然错版**：`theme.ts` 把 `mode` 钉死为 `dark`（Q4-A 时代的决定），
   而预设色值是成对写入 mode 的 → 重启后 body 仍挂 `theme-dark`，
   `--float-*` / `--slip-*` 给深色值，顶栏变成压在浅色页面上的深灰玻璃。
   改为读回 `saved.mode`。
2. **vite 被编辑器临时目录搞崩**：原子保存产生的 `.xxx.tmpdir/` 被 chokidar 追到后
   EBUSY 直接退出 dev server。`vite.config.ts` 的 `watch.ignored` 补上。
