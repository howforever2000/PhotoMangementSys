# 大图预览器（PhotoLightbox）重排方案

> 需求：**照片预览界面不好看，重新布局即可**（不改功能，只改版式）。
> 效果图：`lightbox-a.png` / `lightbox-b.png`（1600×1000，与真实窗口同比例）
> 可复现：`node design/preview/proposal/shoot-lightbox.cjs`
> 源码：`design/preview/proposal/lightbox-a.html` / `lightbox-b.html`

---

## 一、现状为什么"不好看"（逐条对到代码）

| # | 现象 | 代码成因 |
|---|---|---|
| 1 | 照片上**同时压着两条浮层**：顶部快捷键胶囊、底部工具栏 | `.lb-zoombar{position:absolute;top:12px}` 与 `.lb-toolbar{position:absolute;bottom:12px}` 都压在图片区上 |
| 2 | 为了让工具栏不盖图，照片区被**提前让出 54px**，结果图变小了、工具栏还是叠在上面 | `.lb-body{padding-bottom:54px}` 是个补丁，不是布局 |
| 3 | 信息栏像**调试面板**：17 行 `dt/dd` 平铺，拍摄/AI/文件/影调混在一起 | `.lb-meta dl{grid-template-columns:68px 1fr}` 一把梭，无分组、无层级 |
| 4 | 同一个文件名说两遍（标题栏一个、面板里一整条绝对路径） | `.lb-titlebar .lb-title` + `.lb-filename` |
| 5 | 图标全是 **emoji**（🖼 ℹ ⛶ 🏷 ✏️ 📁 📦 🔒 🗑），跟其他页面已统一的线性 SVG 不是一套语言 | `<button>🖼 …</button>` 直接写字符 |
| 6 | 翻页箭头是 **56×80 的整块半透明白片**，比画面最亮处还抢眼 | `.lb-nav{width:56px;height:80px;background:rgba(255,255,255,.15)}` |
| 7 | **三套材质**同场：标题栏 `.06 白`、工具栏 `.74 深`、标签面板 `.88 深`、提示条 `.12 白` | 各写各的 rgba |
| 8 | 计数/倍率到处跑：标题栏有 12/348，面板里还有一份 `.lb-counter`（CSS 里**定义了两遍**），倍率只有缩放后才出现 | `.lb-counter` 重复定义；`.lb-scale` 藏在提示条里 |
| 9 | 翻图**没有上下文**，只能靠箭头盲翻 | 无缩略图条 |

一句话：**不是照片不好看，是照片周围"值班"的东西太多，而且它们互相不认识。**

---

## 二、统一规则（两套方案共用）

1. **照片四周只留一条常驻 chrome**，其余全部让位或按需出现（hover / 快捷键 / 弹层）。
2. **一屏一种材质**：统一 `1px rgba(255,255,255,.07)` 发丝线 + `rgba(255,255,255,.02)` 玻璃底色，不再混 `.12/.74/.88` 三种。
3. **信息按"人怎么读一张照片"排序**：何时 → 何地 → 怎么拍的 → AI 认出了什么 → 文件本身。
4. **层级只靠三样**：字号（11 / 12.5 / 21）、字重（400 / 500 / 600）、文字色三档（`#eef1f7` / `#9aa3b5` / `#767f92`）。
5. **颜色预算**：一屏最多两处强调色 —— 主色 `#6a8df0` 给"编辑"，危险色给"删除"；星级黄只在评分上用。
6. 图标统一 **16px 线性 SVG**（`stroke-width 1.7`），文字按钮只保留高频的三个。

## 三、方案 A（推荐）· 右侧档案栏 + 全宽底栏

```
┌────────────────────────────────────────────────────────────┐
│ ● IMG_2043.ARW  洱海 · 2026-10-28      12/348  ⓘ ⛶ ✕        │ 46
├──────────────────────────────────────────┬─────────────────┤
│                                          │ 2026 · 10 · 28  │
│                                          │ 大理 · 洱海廊道  │
│                照  片                    │ ── 相机 ──────   │
│           （22/26 内边距 + 外阴影）        │ 1/500s   f/8.0  │
│                                          │ ISO100   35mm   │
│                                          │ ── AI 识别 ───   │
│                                          │ 风景·山湖 chips  │
│                                          │ 置信度 ▓▓▓▓ 92%  │
│                                          │ ── 文件 / 直方图 │
├──────────────────────────────────────────┴─────────────────┤
│ ★★★★☆ 4星 │ 标签3 · 编辑 · 在相册中查看   归档 隐藏 删除   │ 60
└────────────────────────────────────────────────────────────┘
```

**改了什么**

- `.lb-body` 从 `flex + padding-bottom:54px` 改成 **grid：`1fr 344px`**；工具栏从绝对定位改为**独立一行 60px**。照片区不再被任何东西压住，`54px` 补丁直接删掉。
- 信息栏重排成 **4 段 + 参数瓷砖**：大字日期（21px，`2026 · 10 · 28` + `17:42`）→ 地点（主色可点）→ 相机 2×2 瓷砖（快门/光圈/ISO/焦距，值 15px 600）→ AI chips + 置信度条 → 文件三行 → 直方图。
- 标题栏 46px：文件名 + `地点 · 日期`，右侧 计数 chip + ⓘ ⛶ ✕ 三个图标。
- 顶部常驻快捷键胶囊**删掉**，改成标题栏 `?` 气泡（hover 才出）；缩放倍率变成标题栏 chip，**仅 ≠ 100% 时出现**。
- 翻页箭头 56×80 方片 → **44 圆形玻璃按钮**，贴在照片区两侧 20px。
- 底栏左到右：星级 → `标签(n)` / `编辑` / `在相册中查看` …… 右侧 `归档` / `隐藏` / `删除`。

**优点**：信息常驻、不压图、窗口范式（拖边缩放 / 双击标题栏全屏 / F11）完全保留，改动只在 template + style，script 逻辑一行不动。
**代价**：右侧 344px 是常驻占位，超宽图（21:9）会被缩得比较小 —— 现有「收起信息」按钮留着，收起后照片区自动吃满。

## 四、方案 B · 沉浸式电影模式

```
┌────────────────────────────────────────────────────────────┐
│ IMG_2043.ARW                                 12/348 ⓘ ⛶ ✕ │
│ 2026-10-28 17:42 · 6000×4000 · 24.6MB              ┌────┐  │
│ ⌖ 云南大理 · 洱海生态廊道                            │ 🏷 │  │
│                                                    │ ✎  │  │
│                    照  片  铺  满                    │ 📁 │  │
│                                                    │ 📦 │  │
│                                                    │ 🔒 │  │
│                                                    │ 🗑 │  │
│                        ★★★★☆ 4 星                   └────┘  │
│              ┌───────────────────────────┐                  │
│              │ 9 [thumb][thumb][cur]…348 │                  │
│              └───────────────────────────┘                  │
└────────────────────────────────────────────────────────────┘
```

**改了什么**

- 去掉窗口框（或仅全屏时去掉），照片铺满，上下用渐变压暗承托文字，左上角裸文字叠加文件名/时间/地点（无底板）。
- 右侧一条**竖向图标轨**（标签/编辑/相册/归档/隐藏/删除），底部**胶片条**（前后各 2 张，当前张白边高亮）+ 星级。
- 完整信息走右侧抽屉（复用现有「收起信息」逻辑反转为「展开信息」，快捷键 `I`）。

**优点**：照片最大，最像看图软件，翻图有前后文。
**代价**：信息不再常驻，只有一行摘要；「档案感 / 严肃感」弱于 A；胶片条需要读缩略图 URL（现有 `thumbQueue` 已有能力，但要接一层）。

## 五、建议

**选 A**。它解决的是现状的**根因**（浮层压图 + 信息无层级），而不是把浮层挪个位置；
同时保住 FEAT-096 的窗口范式与所有既有交互，改动面最小（`PhotoLightbox.vue` 只动 `<template>` 与 `<style>`）。
如果之后想要 B 的"看电影"体验，A 的骨架可以直接切全屏模式时启用（同一套结构，全屏时信息栏变抽屉、底部 dock 变胶片条）。

## 六、落地清单（原子化，可独立回滚）

1. `titlebar`：emoji → 内联 SVG；清掉重复的 `.lb-counter` 定义；加 `?` 气泡与缩放 chip。
2. `body`：`flex` → `grid-template-columns: 1fr 344px`；删除 `padding-bottom:54px`。
3. `meta`：`<dl>` 拆成 4 组（相机瓷砖 / AI chips + 置信度 / 文件 / 直方图）；日期与地点提到顶部。
4. `dock`：`.lb-toolbar` 从 `position:absolute` 改为流内 60px 行；按钮分组重排。
5. `nav`：56×80 → 44 圆形；`.lb-zoombar` 删除。
6. `style`：材质统一为一种发丝线 + 一档玻璃底；字阶收敛到 7 档令牌（`--fs-*` / `--c-*`）。
7. **不动**：缩放/平移、快捷键、FEAT-D 静默扫描、评分/归档/隐藏/删除 emit、窗口拖拽与全屏。

## 七、验证口径

- 1280×800 与 1920×1080 两个窗口尺寸下，照片**四周不出现任何覆盖物**（放大到 250% 平移时也不压）。
- 信息栏收起后照片区**吃满**，展开/收起无跳动。
- 键盘 `1-5` / `←→` / `Esc` / `F11` / `Ctrl+滚轮` 行为不变。
- 全屏与窗口两种状态下，标题栏与底栏高度一致、不塌陷。
