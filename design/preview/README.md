## 二、导航：顶栏只导航**本组件内部**

> 这一节走过三次弯路，下面是定稿。
>
> | 版本 | 顶栏内容 | 为什么错 |
> |---|---|---|
> | 第 1 版 | 相册 / 时间线 / 人物 / 地点 / 语义 | 后四项是 `/smart` **内部**的 tab，却和「相册」平起平坐 |
> | 第 2 版 | 整条删掉，只留「← 主页 + 组件名」 | 矫枉过正：组件内部确实需要一条常驻分区导航 |
> | **第 3 版** | **只放当前组件内部的分区** | 跨组件只有一个出口：`← 主页` |

```
[← 主页] [🧠 智慧相册 · 12 个相册] │ 人物  内容分类  地点  回忆  时间线  智能搜索        [搜索] [头像]
         ↑ 组件名 + 读数              ↑ 全部属于「智慧相册」这个大组件
```

- **顶栏不放任何其他组件的入口**。想看扫描入库？点「← 主页」回 Home 换。
- 分区与组件名之间用一条发丝竖线分隔，让「我是谁」和「我能去哪」读成两件事。
- 分区数量由各页自己定（智慧相册 6 项 · 扫描入库 4 项 · 相册管理 0 项）。

**各组件内部的分区**：

| 组件 | 分区 |
|---|---|
| 智慧相册 | 人物 / 内容分类 / 地点 / 回忆 / 时间线 / 智能搜索 |
| 扫描入库 | 全局扫描 / 按年·地点（待开发，置灰）/ 重复清理（待开发，置灰）/ 扫描分组工具 |

## 三、相册管理：双栏，左栏是筛选不是导航

参考图的版式：左边一列窄筛选，右边是内容。

```
┌─ 顶栏：[← 主页] 📁 相册管理 · 12 个相册            [搜索] [头像]
├─ 数据带：相册 12 · 照片 653 · 已入库 10 · 待入库 2 · 占用 18.4 GB
└─ 双栏
   ├─ 左栏 188px（吸顶）      └─ 右栏（自适应）
   │  排序：按时间/按地点/手动排序     内容头：12 个相册  [全部折叠][批量导入][批量管理][新建]
   │  入库：全部12 / 已入库8 / 未入库4   搜索栏
   │  年份：全部年份12 / 2026 3 / …   时间路线图
   │  快捷：全部折叠 / 批量管理         年 → 季 → 月 分组 + 瓦片墙
```

**为什么筛选放左栏而不放顶栏**：顶栏只有 56px，塞不下「3 个排序 × 3 个入库状态 ×
8 个年份」的可点区域；硬塞会让顶栏变成设置面板。

**筛选是真的会过滤**（已实测）：

```
初始          12 个相册
点「已入库」    8 个相册 · 已入库
再点 2026 年    3 个相册 · 2026 年 · 已入库
点「清除筛选」  12 个相册
```

三项筛选叠加在 `visibleAlbums` 上，虚拟相册（归档 / 隐藏）不受影响。
选择写 localStorage，刷新后视图能留住（与 `sortMode` 一致的做法）。

**删掉的重复控件**：工具栏里原有的「排序方式」下拉 —— 左栏已有同名选项，
两处控制同一个值只会让人怀疑哪个生效。

## 三、主题：6 套 → 8 套（不删，只加）

| 组 | 名称 | 三段渐变 | compColor / α |
|---|---|---|---|
| 深 | 落日紫夜（默认） | `#3b2b52 / #271d37 / #120e1c` | `#2a2630` / .62 |
| 深 | 墨色石板 | `#2c3440 / #1d232d / #0e1116` | `#26282c` / .62 |
| 深 | 余烬暖褐 | `#3a2a22 / #261a16 / #120c0a` | `#2b2521` / .62 |
| 深 | **深空石墨**（新增） | `#1d2833 / #131b24 / #080c11` | `#1f2429` / .62 |
| 浅 | 亚麻浅灰 | `#f4f1ec / #e6e2da / #cfc9be` | `#efeeec` / .72 |
| 浅 | 雾光冷灰 | `#eef1f4 / #dae0e7 / #bcc5cf` | `#ededef` / .72 |
| 浅 | 纸白暖中性 | `#faf8f5 / #f0ece6 / #ddd7cd` | `#f4f3f1` / .72 |
| 浅 | **晨雾青瓷**（新增） | `#eaf1ee / #d8e5df / #b6cbc2` | `#eef4f1` / .72 |

**为什么加而不减**：预设是用户自己的外观，砍掉任何一套都会让用它的老用户开屏变样。质感来自每套内部的**明度跨度**，不来自套数少 —— 那才是真正的不变量。

新增两套的分工：

- **深空石墨**：比墨色石板再深一档、再冷一档。照片多的页面最省心 —— 底越深，封面自己的色彩越跳得出来。
- **晨雾青瓷**：浅色里唯一的冷绿。树 / 水 / 草占比高的库，用暖白或冷灰都会把绿色压成灰绿。

两套沿用各自的 `compAlpha`（深 .62 / 浅 .72）与 `plain` 材质，与既有 6 套同构；`compColor` 通道极差 ≤ 12，通过既有"素"阀值（石墨首版 `#1a222a` 极差 16 被测试拦下，改 `#1f2429`）。

## 四、材质：液态玻璃保留，新增纸片分工

**液态玻璃一点没动** —— `--glass-*` 令牌与 `.glass-float` 类原样保留，继续只用于**浮在内容之上**的层：搜索胶囊、抽屉、灯箱工具条、弹窗、右键菜单、Toast、工坊画布 HUD。

新增的是**纸片（paper slip）**，给躺在内容**之中**的块用（统计面板、侧栏分组、任务卡）：

```css
/* 深色：只提亮 3.4%，靠明度差读厚度 */
--slip-fill: rgba(255,255,255,.034);
--slip-top:  rgba(255,255,255,.062);   /* 上缘光 */
--slip-shadow: 0 1px 2px rgba(0,0,0,.34), 0 18px 40px -30px rgba(0,0,0,.9);

/* 浅色：白纸落在米色台面，厚度全靠投影（提亮到白没有上限） */
--slip-fill: rgba(255,255,255,.68);
--slip-top:  rgba(255,255,255,.95);
--slip-shadow: 0 1px 2px rgba(23,22,26,.06), 0 14px 30px -24px rgba(23,22,26,.4);
```

两者**刻意不合并成一个类**：一个模糊、一个不模糊，混在一起就会出现"同一块地方有时模糊有时不模糊"的不可预测。

为什么卡片不用玻璃：卡片是结构元素，一屏几十张，每张 `backdrop-filter` 会让文本背后的颜色一直变，读数不稳（FEAT-103 当初删 34 处的理由仍成立）。纸片只承载一个信号 —— "这块是独立的一块"，不承担任何背景透传。

## 五、密度：只动间距，不动瓦片结构

| 位置 | 改动 | 结果 |
|---|---|---|
| 相册 tile 网格 | `minmax 216→208`、`gap 30/26→12/12`、加 `grid-auto-flow: dense` | 同宽度多容一列；折叠分组后的尾位被填满，不留空洞 |
| 人物网格 | `minmax 220→176`、`gap 16→12`、加 `dense` | 同屏 5 列 → 7 列，扫脸效率明显上升 |

**为什么不给瓦片加底 / 加框 / 加影**：封面本身已经是内容，加了就成了"贴纸墙"。一屏的信息量由"列数 × 行距"决定。

**取舍记录**：效果图里"每 5 张一张 2×2 重点瓦片"**没有落地**。它要求封面高度从固定 160px 改为随行高走、标题从卡片下方移入封面浮层 —— 等于重写 `AlbumCard` 的版式。按"前端不要太重"的约束先不做，列为可选后续。

### 效果图里的渐变 hero 为什么必须删

它不是一个"配色选择"，是一个**层级错误**：hero 里的 4 张渐变入口卡把
"人物 / 回忆 / 时间线 / 搜索" 提到了与模块同高的位置，而它们本来只是本模块内部的
小功能。结果同一组功能在一屏里出现三遍（顶栏一遍、入口卡一遍、下方的胶囊 tab 一遍），
用户无法判断"我现在到底在哪一层"。

删除后的对应关系：

| 原来 | 现在 |
|---|---|
| 彩虹 hero 的大标题 + 副标题 | 模块页头（emoji + 模块名 + 一行读数） |
| hero 里的 5~6 格统计 | `StatBand` 数据带（同样一组数，不丢任何一项） |
| 4 张渐变入口卡 | 顶栏的分区导航项（`AppHeader.tabs`） |
| 下方那排胶囊 tab | 同上（两排合并为一排，不再重复） |

## 九、复现

```bash
node design/preview/shoot-all.cjs   # 需要 playwright + msedge
```

- `all.html` 一个文件装 16 个界面，每屏是 `<div class="shot t1|t2|t3|t4" id="sN">`
- `inner.css` = 组件样式（纸片 / 瓦片 / 数据带 / 任务表 / 编辑器 / 二级导航）
- `all.css` = 4 套主题令牌 + 新增板块（时间线 / 回忆 / 搜索 / 地点 / 语义 / 灯箱 / 主题弹窗）
- `tokens.css` 不再复制，直接引用 `../../src/assets/tokens.css`（避免与真实令牌漂移）
- `assets/p1~p12.jpg` 与渲染出的 PNG 不入库（体积大、可重现）

⚠️ 坑 1：`tokens.css` 的浅色规则挂在 `body:not(.theme-dark)`，审稿页没有 body 类会命中浅色，所以每套 `.tN` 里都就地重声明了整套 `--c-*`。

⚠️ 坑 2：`inner.css` 里 `.hd` 是旧顶栏（带背景 + sticky + 56px 高），与表头 `.qrow.hd` 同名，`all.css` 里必须把 `.qrow.hd` 的背景与高度抹平，否则表头会被涂成浅色块。
