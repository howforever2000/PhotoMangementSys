# 设计系统 · Canvas 极简 + 液态浮层

> 版本 v1 · 2026-10 · 目标分支 `dev`
> 参考：Rainmeter 皮肤（栅格纪律 / 字阶 / 克制用色）+ 相册管理品类惯例（常驻浏览、内容为主语）

---

## 一、核心主张（三条）

1. **内容即界面**：照片/封面本身就是视觉主体，容器（卡片）退场。层级由留白与发丝线建立，不由边框与阴影建立。
2. **数据不删，去壳**：所有统计信息保留，但从「卡片壳」改为「数据带 / 行内统计 / 角标」三种更轻的载体。
3. **玻璃只做浮层**：液态玻璃仅出现在真正"浮在内容之上"的层（搜索、抽屉、灯箱工具条、弹窗、Toast）。卡片不再是玻璃 —— 稀缺才有质感。

## 二、设计令牌（新建 `src/assets/tokens.css`）

### 2.1 字阶（20 档 → 6 档）

| 令牌 | 值 | 用途 |
|---|---|---|
| `--fs-label` | 9.5px / 字距 .14em / 大写 / uppercase | 所有统计标签、分组头 |
| `--fs-meta` | 11px / 字距 .02em | 元信息、次级说明、缩略图计数 |
| `--fs-body` | 12.5px / 字距 .01em | 导航、按钮、正文 |
| `--fs-title` | 13px / 字距 .008em / 560 | 相册名、卡片标题 |
| `--fs-head` | 19px / 字距 -.2px / 600 | 年标题、区块标题 |
| `--fs-metric` | 25px / 字距 -.5px / 560 | 数据带读数（tabular-nums） |
| `--fs-display` | 33px / 字距 -.9px | 大读数（详情页、回忆页） |

配套：全局 `letter-spacing: .006em`；所有数字 `font-variant-numeric: tabular-nums`（沿用现状）。

### 2.2 字重（4 档 → 3 档）

`400` 正文 / `560` 强调（替代 500/600 混用）/ `650` 标题与读数。

> 560 与 650 是可变字重的中间档，本机字体栈（Segoe UI Variable / PingFang SC）均支持；不支持时退化为 500/600，视觉差可忽略。

### 2.3 间距（8 基数）

`--sp-1: 4px` `--sp-2: 8px` `--sp-3: 12px` `--sp-4: 16px` `--sp-5: 24px` `--sp-6: 32px` `--sp-7: 40px` `--sp-8: 52px`

- 页面左右留白：`--sp-8 (52px)`
- 卡片间距：`--sp-5 / --sp-6`（网格 gap 30px，行 gap 34px）
- 区块之间：`--sp-6 (32px)`

### 2.4 圆角（12 档 → 3 档）

`--r-cover: 5px`（封面）· `--r-ui: 8px`（按钮/输入/菜单项）· `--r-pill: 999px`

### 2.5 动效（14 种时长 → 3 档 × 2 曲线）

| 令牌 | 值 | 用途 |
|---|---|---|
| `--dur-1` | 90ms | 按压、颜色微变 |
| `--dur-2` | 180ms | 悬停、边框、透明度 |
| `--dur-3` | 280ms | 抽屉、弹窗、页面切换 |
| `--ease-out` | `cubic-bezier(.22,.61,.36,1)` | 进入/离开（默认） |
| `--ease-both` | `cubic-bezier(.4,0,.2,1)` | 尺寸/位置过渡 |

**只允许动 `transform` 与 `opacity`**（例外：颜色/边框色/背景色，这些不触发布局）。

### 2.6 层级

`--z-bg: 0` · `--z-content: 1` · `--z-sticky: 20` · `--z-rail: 40` · `--z-drawer: 60` · `--z-modal: 80` · `--z-lightbox: 100` · `--z-toast: 120`

### 2.7 色彩预算

| 角色 | 令牌 | 值（dark） | 用途 |
|---|---|---|---|
| 背景 | `--c-bg` | `#0a090d` | 页面底 |
| 前景 | `--c-fg` | `#f2f0f4` | 主文字 |
| 次要 | `--c-fg-2` | `rgba(242,240,244,.46)` | 导航、次级文字 |
| 弱化 | `--c-fg-3` | `rgba(242,240,244,.26)` | 元信息、单位 |
| 发丝线 | `--c-rule` | `rgba(255,255,255,.075)` | 分隔 |
| 强调 | `--c-accent` | `#d4a24a` | **唯一**强调色：当前项、变化值、图表高亮 |
| 语义危险 | `--c-danger` | `#d96a6a` | 仅删除/错误 |

浅色对应：`--c-bg: #faf8f5` · `--c-fg: #17161a` · `--c-fg-2: rgba(23,22,26,.44)` · `--c-fg-3: rgba(23,22,26,.30)` · `--c-rule: rgba(23,22,26,.085)` · `--c-accent: #9a6f2a`。

> **删除**：`--candy-cream/pink/blue/rose/indigo/violet` 六色令牌（糖果彩虹）不再用于卡片；若需保留品牌，仅用于登录页封面叠色。
> **保留**：`--color-ok*` / `--color-warn*` 降级为"仅状态徽标"使用，不进图表、不进强调。

## 三、材质分职（关键变更）

| 层 | 材质 | 规格 |
|---|---|---|
| 页面底 | 纯色 + 极淡双径向光晕 | `radial-gradient(58% 44% at 14% -6%, rgba(120,88,60,.18), transparent 66%)` ×2 |
| 卡片 / 相册封面 | **无容器** | 裸封面 + `inset 0 0 0 1px rgba(255,255,255,.09)` |
| 数据带 | **无容器** | 只有发丝分隔线 |
| 导航栏 | 无背景 | 底部 1px `--c-rule` |
| **液态浮层** | 液态玻璃 | 见 3.1 |
| 抽屉 | 液态玻璃 | 同上，宽度 320px |
| 灯箱工具条 | 液态玻璃 | 同上，高 44px |

### 3.1 液态玻璃规格（深色）

```css
--glass-fill: rgba(30, 27, 34, .62);
--glass-border: 1px solid rgba(255, 255, 255, .10);
--glass-blur: blur(16px) saturate(1.1);
--glass-shadow:
  /* ① 上缘镜面（1px 硬） */
  inset 0 1px 0 rgba(255,255,255,.34),
  /* ② 下缘暗壁（1px 硬）—— 厚度的读数 */
  inset 0 -1px 0 rgba(0,0,0,.36),
  /* ③ 环境柔光（唯一外层阴影） */
  0 10px 24px -14px rgba(0,0,0,.70);
```

### 3.2 液态玻璃规格（浅色）

```css
--glass-fill: rgba(255, 255, 255, .72);
--glass-border: 1px solid rgba(255, 255, 255, .95);
--glass-blur: blur(16px) saturate(1.15);
--glass-shadow:
  inset 0 1px 0 rgba(255,255,255,1),
  inset 0 -1px 0 rgba(120,105,88,.14),
  0 10px 22px -14px rgba(110,88,60,.42);
```

> **对比现状**：`--shadow-1` 现有 6 层 inset → 收为 **3 层**。原因：6 层叠起来是"整片灰白"，壁厚反而读不出。1.5px 棱环 `::after` → **1px** 单光源 158°。
> **不透明下限**：液态 `compAlpha` 不得低于 0.58（现状 0.52 会让背景光透进卡面，把数据区压成灰色）。

## 四、组件规格

### 4.1 数据带 StatBand（替代统计卡片）

- 高度 86px，横向排列，发丝竖线分隔（`1px × 38px`，居中）
- 每格结构：`label(9.5px)` → `value(25px)` → `sparkline(46×16)`
- 值后缀：单位 10.5px 弱化；变化值 10px 强调色（正向）或弱化（持平）
- 右侧可选内联图：44px 高柱阵，无轴、无网格

### 4.2 相册卡 AlbumTile

- 结构：封面（`aspect-ratio: 16/10`，`--r-cover`）+ 图注（`padding-top: 11px`）
- 图注：左名字 `--fs-title` / 右统计 `--fs-meta` 弱化（`108 · 人物 42`）
- 悬停：`filter: brightness(1.06)` + 封面内描边提到 `.16`，**不位移、不加阴影**
- 按压：`transform: scale(.985)` / 90ms
- 角标：左上 9px 大写（`已扫描` / `未扫描`）

### 4.3 行内统计 GroupStat（组级）

- 与组标题同基线：`2026   5 个月 · 388 张 · 平均 78/月   ▃▅▄▆█`
- 数字 `560` + 弱化，分隔符 `·`
- 右侧迷你分布柱：宽 5px、gap 2px、高 13px，当前项强调色

### 4.4 顶栏与导航

- 高 56px，无背景，底部 1px 发丝线
- 导航项 `--fs-body` 弱化，当前项前景色 + 1.5px 强调下划线（`bottom: -2px`）
- 搜索胶囊：唯一的玻璃元素（见 3.1），右侧 `⌘K` 提示
- 头像 26px 圆形

### 4.5 交互手感（全站统一）

| 项 | 规格 |
|---|---|
| 悬停 | 只改颜色/亮度，`--dur-2` |
| 按压 | `scale(.985)`，`--dur-1`；**所有可点击元素必须有** |
| 焦点 | `outline: 1.5px solid var(--c-accent); outline-offset: 2px` |
| 热区 | 最小 40×40px（图标按钮需用透明 padding 补足） |
| 滚动 | `overscroll-behavior: contain`；滚动条宽 8px、thumb 20% 白、轨道透明 |

## 五、页面骨架

```
┌──────────────────────────────────────────────┐
│ 顶栏 56px：品牌 · 导航 · 搜索胶囊 · 头像       │ ← 发丝线
├──────────────────────────────────────────────┤
│ 数据带 86px：label / value / sparkline ×N      │ ← 发丝线
├──────────────────────────────────────────────┤
│ 区块头：标题 + 组级统计 + 排序                  │
│ 内容区：裸封面网格 / 时间线长卷 / 地点地图      │
└──────────────────────────────────────────────┘
```

**导航形态决定**：顶栏常驻（不用侧边栏）。抽屉式侧栏由左上角品牌点击或 `⌘B` 呼出，承载 `归档 / 隐藏 / 扫描 / 工坊 / 设置` 等低频入口。

理由：相册的核心行为是「横向浏览大量封面」，纵向侧栏会永久占用 200px 的封面空间；顶栏 56px 换来的封装比更高。低频入口走抽屉。

## 七、预设（10 套 → 6 套，深浅配对）

| id | 名称 | mode | 渐变（起 → 中 → 止） | compColor | compAlpha |
|---|---|---|---|---|---|
| `sunset-dusk` | 落日紫夜 | dark | `#3b2b52 → #271d37 → #120e1c` | `#2a2630` | 0.62 |
| `ink-slate` | 墨色石板 | dark | `#2c3440 → #1d232d → #0e1116` | `#26282c` | 0.62 |
| `ember-warm` | 余烬暖褐 | dark | `#3a2a22 → #261a16 → #120c0a` | `#2b2521` | 0.62 |
| `linen-light` | 亚麻浅灰 | light | `#f4f1ec → #e6e2da → #cfc9be` | `#ededed` | 0.72 |
| `mist-light` | 雾光冷灰 | light | `#eef1f4 → #dae0e7 → #bcc5cf` | `#ececec` | 0.72 |
| `paper-light` | 纸白暖中性 | light | `#faf8f5 → #f0ece6 → #ddd7cd` | `#efeeec` | 0.72 |

**删除 6 套**：`sage-rose` `cream-violet` `mint-indigo` `butter-plum` `lemon-teal`（多色相，与"单强调色"预算冲突）、`clay-warm` `amber-warm` `slate-cool`（与保留的暖褐/冷灰撞色相）。

> 兼容策略：`normalizePrefs()` 遇到已删除的 preset 色值不报错，视为自定义配色（用户手动调过的也走这条），只丢失"预设命中高亮"，外观不变。

**新增字段**：`Preset.mode: "dark" | "light"`；`presetPrefs()` 一并下发 `mode`；`PRESET_GROUPS` 改为按模式分两组（「深色」/「浅色」）；`ThemeDialog` 增加模式切换。

## 八、地点地图（新增）

见 `.pi/plan.md` P3。要点：
- 底图用**现有** `src-tauri/resources/china_geo.json`（2.89MB / 35 省 / 160k 点），前端另生成一份精简版 `public/china-provinces-lite.json`（仅省级轮廓，DP 容差 0.02°，目标 ≤ 300KB，懒加载）
- 地图本体：等距圆柱投影，省级轮廓仅 `4%` 白描边（几乎不可见），**不留任何网格/经纬线/图例**
- 点亮：每个城市点位一个金色光点，半径 `3 + 2.2·ln(count)`，`box-shadow` 光晕；热门点位附带城市名
- **空即信息**：没有点的地方就是空的，不画占位、不画"暂无数据"标记 —— 这正是让"未覆盖"可见的方式
- `未记录地点` 不入图，单独在图表下方以一行显示 `31 张 · 无 GPS / 境外`
